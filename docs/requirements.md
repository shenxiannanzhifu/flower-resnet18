## 用户要求与实现选择

以下来自用户要求，不是把 PDF 原文扩大解释：分版本迭代、每版实际验收/提交/标签、每版结束暂停、手写 **ResNet-18**、清晰中文注释、严格区分试运行与正式结果、查重和防数据泄漏、禁止擅自付费/公开/上传敏感信息。

PDF 要求手写 ResNet，但未限定 18 层、准确率门槛、训练轮数、固定数据集、数据库、网站或云服务。花卉分类是 PDF 提供的参考方向之一。选择五类花卉数据、Python 3.12、CUDA 12.8 和命令行程序是本项目的实现决定；不增加网站、数据库或云部署。

PDF 鼓励拓展学习和创新，并未要求额外系统。先完成可运行、有解释和证据的核心项目。参考项目链接来自 PDF，仅作为需求背景，当前没有复制其实现。
